# stablemap

<!-- badges: start -->

<!-- badges: end -->

This package provides statistical methods for stabilized disease mapping
and tools for generating space-time simulation data. The supported
methods include:

- Stabilized Kriging ([Hsu et al.,
  2023](https://doi.org/10.2188/jea.JE20210276))
- Stabilized Spatiotemporal Kriging ([Tsai et al.,
  2022](https://doi.org/10.1186/s12874-022-01749-9))
- Age-Period-Cohort Kriging

## Installation

You can install the development version of `{stablemap}` from GitHub
with:

``` r
pak::pak("darentsai/stablemap")
```
